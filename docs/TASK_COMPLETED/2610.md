precargaba entero.

- [x] Quitado el `return 'vendor'` de `manualChunks` en `vite.config.ts` — Rollup deja las deps solo-lazy en los chunks lazy (`SubscriptionsPage` absorbe qrcode/jsbarcode, `DiaryPage`/`HouseholdPage` comparten `date-fns`+locale `es`); los buckets eager `react-vendor`/`ui-vendor`/`utils-vendor` se quedan para caching
- [x] `scripts/bundle-smoke.mjs` — corre al final de `npm run build`: detecta ciclos en el grafo estático de chunks (la regresión de PR #19) e importa cada `*vendor*.js` en Node para reproducir el crash de init-order (`Cannot set properties of undefined`); los chunks de página se omiten porque tocan `document` al evaluar
- [x] README §Bundle splitting actualizado (ya no existe el bucket `vendor`)

> Contexto: también se midió quitar `manualChunks` por completo — un solo
> `index` de 447 kB (139 kB gz). Es ~10 kB gz más chico que la suma de chunks
